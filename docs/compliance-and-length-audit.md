# Проверка соответствия российским требованиям и фактического объёма

**Дата проверки:** 7 ноября 2026 года. **Статус:** структурный аудит предварительного научного макета, не допуск к защите.

## Нормативные основания

- [ГОСТ Р 7.0.11–2011](https://protect.gost.ru/gost/details/80cb3ff3-6f82-4267-9122-0873213d8d53) «Диссертация и автореферат диссертации. Структура и правила оформления». Для рабочего чтения требований см. [текст стандарта](https://meganorm.ru/Data2/1/4293793/4293793489.htm).
- [Постановление Правительства РФ № 842 от 24.09.2013](https://sudact.ru/law/postanovlenie-pravitelstva-rf-ot-24092013-n-842/) — положение о присуждении учёных степеней, редакция от 18.07.2026.

## Проверка содержания

| Требование | Статус |
| --- | --- |
| Тема, объект, предмет, цель, задачи, рамки | Есть в черновике введения |
| Актуальность, историография, методология | Есть, но историографический обзор требует полного чтения книг |
| Источниковая база | Намечена; акты не обработаны сплошным методом |
| Научная новизна | **Не доказана**; вместо неё обозначены гипотезы |
| Положения на защиту | Только проверяемые тезисы, не результаты |
| Достоверность | Протокол задан, источниковая проверка не завершена |
| Апробация и публикации | Нет подтверждённых сведений; **не заявлены** |
| Основная часть | Четыре главы предварительного аналитического текста |
| Заключение | Есть, с разделением подтверждённого и непроверенного |
| Список литературы | Первичный каталог; не полный научный аппарат |
| Титульный лист, оглавление с номерами страниц | **Нет в оформленном виде** |
| Сноски с проверенными страницами первоисточников | **Нет**; нельзя подставлять произвольные номера |
| Реальная 30-страничная вёрстка | **Не выполнена**; число страниц не заявляется |

## Требования к последующей вёрстке

ГОСТ Р 7.0.11–2011 для рукописи предусматривает титульный лист, оглавление, введение, основную часть, заключение и список литературы. Приложения, словарь терминов и списки сокращений предусмотрены при необходимости. Текст печатается на А4, межстрочный интервал — 1,5, шрифт 12–14 пт; поля: слева 25 мм, справа 10 мм, сверху и снизу по 20 мм. Титульный лист учитывается в нумерации, но номер на нём не печатается; на следующей странице ставится «2». Каждая глава начинается с новой страницы. Перед оформлением под конкретную организацию необходимо проверить её дополнительные требования.

Неизвестные реквизиты (организация, научная специальность, учёная степень консультанта, место защиты, сведения о соискателе) нельзя выдумывать: для титульного листа следует оставить пустые поля, пока не получены достоверные данные.

## Фактический подсчёт текста

Подсчёт выполнен по шести файлам `manuscript/*.md` методом выделения последовательностей русских/латинских букв и цифр; это **приближённый подсчёт слов**, в который входят заголовки и части ссылок. Итог:

| Файл | Слов |
| --- | ---: |
| 00-introduction.md | 1 752 |
| 01-historiography-and-sources.md | 1 687 |
| 02-boyar-duma-structure.md | 1 311 |
| 03-duma-and-tsar-1606-1608.md | 1 516 |
| 04-crisis-1608-1610.md | 1 407 |
| 05-conclusion.md | 670 |
| **Итого** | **8 343** |

В расчёт не включены библиография, титул, оглавление и план презентации. Количество **страниц не измерено**, потому что не создан единый постранично свёрстанный PDF/DOCX с проверенными переносами и полями. **Нельзя утверждать, что макет уже занимает ровно 30 страниц**.

## Научная оценка

В отличие от формальной структуры, степень готовности научного исследования пока невысока: главы преимущественно формулируют методологию и вопросы, а не приводят собственные результаты анализа документов. Увеличение числа слов само по себе не исправит этот недостаток. Следующий этап — работа с первичными источниками и создание доказательных ссылок.

**Итог:** структурный макет подготовлен; требованиям готовой докторской диссертации **не соответствует**, поскольку отсутствуют результаты самостоятельного исследования, проверенные постраничные ссылки, установленная новизна, публикации и апробация.
